# どうぶつ保護データプロジェクト　アカウントの扱いについて（事務局向け）

作成日：2026年10月5日

このシステムには、団体の担当者名・連絡先と、保護した動物の頭数の統計が入っています。里親さんや飼い主さんの個人情報は入っていません。それでも、団体から預かった情報を守るために、アカウントの扱いで次のことを守ってください。

## 1. 事務局アカウントについて

- 事務局アカウントは、全団体のデータと連絡先を見られる強い権限です。
- 必要最小限の人数（2〜3名）にしてください。
- 担当を外れた人のアカウントは、その日のうちに「設定 → ユーザー」から停止してください。
- パスワードは12文字以上、他のサービスと使い回さないものにしてください。

## 2. 団体アカウントを作るとき

- 「設定 → ユーザー → ユーザーを追加」で作成します。
- 権限は必ず「団体ユーザー」、所属団体を正しく選んでください。間違えると、その人が他団体のデータを見られる状態になります。
- 作成後に一度だけ表示される「ログイン情報」をコピーして、本人に伝えます。この画面を閉じると初期パスワードは二度と表示されません。

## 3. 初期パスワードを伝えるとき

- 伝える相手が、その団体の担当者本人であることを確認してください。
- メールで送る場合は、「ログインURL・メールアドレス」と「初期パスワード」を別々のメールに分ける、または電話で伝えるのが安全です。
- 本人に「ログイン後、アカウント画面でパスワードを変えてください」と伝えてください。システムからも変更をうながす表示が出ます。

## 4. パスワードを忘れた・担当者が替わったとき

- 「設定 → ユーザー → パスワード再発行」で新しい初期パスワードを出します。古いパスワードはその時点で使えなくなります。
- 再発行の依頼は、本人確認をしてから行ってください（登録してあるメールアドレスからの依頼であることなど）。
- 担当者が替わる場合は、前の人のアカウントを「停止」し、新しい人のアカウントを新しく作ってください。アカウントの使い回しはしないでください。

## 5. 絶対にしないこと

- パスワードをチャットツールやグループメールなど、複数人が見る場所に書かない。
- システムの管理用の鍵（Supabase の service_role キー、Vercel の環境変数）をメールやチャットに貼らない。
- 共有パソコンでログインしたまま離席しない。使い終わったら「ログアウト」。
- データの控え（Excel）を、個人のスマホや私用クラウドに保存しない。保存先は事務局の Google ドライブに限る。

## 6. 毎月やること

- 提出期限のあと、確定作業が終わったら「設定 → データの控え」から Excel をダウンロードし、事務局の Google ドライブの「年月」フォルダに保存する。古いファイルは消さない。
- 「設定 → 変更履歴」をざっと見て、心当たりのない操作がないか確認する。

## 7. 困ったとき・不審なことがあったとき

- 身に覚えのないログインや操作を見つけたら、まず該当アカウントを「停止」し、システム担当に連絡してください。
